Behavior Hub - Quick start
From setup to a saved behavioral video.
  1. Create or open a project. Choose New Project or Open Project. Recordings and settings are saved in the project folder.
  2. Choose the behavior and duration. Use Test mode for a short check in seconds. For Custom, enter the behavioral test name. MP4 names use date, time, behavioral test and Mouse ID. Enter Mouse ID under Optional mouse information; if blank, the app assigns Auto_ID01, Auto_ID02, Auto_ID03. Auto_ID means an automatically assigned mouse ID when Mouse ID is blank. The project saves the numbering and continues it after restart.
  3. Select your camera. For a C920, choose HD Pro Webcam C920. Set the resolution and target FPS.
  4. Check the preview. Click Open preview and check framing and lighting. To fix focus, choose Manual and drag the slider until the image is clear. Changes apply automatically and save in the current project. Zoom and flip offers 1-4x digital zoom, pan arrows and horizontal/vertical flips. Framing updates immediately without closing preview. Changes apply to BOTH preview and saved MKV/MP4, at the selected output resolution. Reset restores the full view. Zoom crops away part of the original view; no separate uncropped recording is kept.
  5. Record. Click Start recording. It stops after the selected duration. The yellow timer beside Stop early and save shows the remaining recording time. To finish sooner, use Stop early and save.
  6. Check the saved video. Close preview to allow background processing, or click Process pending videos. New videos appear together in the project MP4 folder after verification. Wait for MP4: verified and review the quality results. A REVIEW result needs checking before analysis. Click View in Record library for details and Open video for playback. The processing queue is below the library.
  7. Finish or analyze. Names are fixed at recording start; duplicates get a number. Older recordings keep their locations. Select one behavior and exclude TEST videos before DLC; keep its matching CSV beside it. Use Exit application when finished. To move your work, copy the entire project folder.
Before an experiment: make a short test recording and check the saved video's focus and framing.
